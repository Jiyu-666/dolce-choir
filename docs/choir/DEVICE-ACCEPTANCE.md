## 数据与质量门槛

| 项目 | 方法 / 合格要求 | 已有证据与剩余 |
|---|---|---|
| 确定性音乐 | 手写 MusicXML 预期逐音、拍位、反复、变速全部一致；不由被测解析器生成预期 | 自动样例已通过；不等于任意新谱免校对 |
| 稳定合成音 | 预先固定频率/谐波/响度矩阵，至少95%有效帧误差≤20音分；另记无效帧比例 | 504/504有效帧通过；强二次谐波另记失败约+1200音分 |
| 真实人声 | 在调参前按演唱者/片段分开调参集与独立验收集；先固定容差再测验收集，分别报告覆盖率/音准/不可判定起音 | 未开始，不能以合成结果宣称通用准确率 |
| 静音/噪声 | 安静、白噪声、敲击不能连续显示正确；记录每段总时长/错误连续时长 | 合成测试通过，真实环境待测 |
| 反馈延迟 | 目标≤250ms：用独立可见发声起点与屏幕反馈共同计时（外部视频/回环方法），报告采集/算法/显示是否包含，至少20次的中位数/P95及异常 | 合成分析中心滞后约42.7ms仅代表算法管线，不是人声端到端指标 |
| 音轨/内存 | 手机长曲实际导出，记录曲长、完成时间、可用的峰值内存测量或浏览器退出/卡顿；设备听感确认 | 桌面600秒MP3解码验证通过，手机未测 |
